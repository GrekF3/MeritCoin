# Чек-лист проекта

## Репозиторий

- [x] Репозиторий подготовлен для публикации.
- [x] Исходный код приложения организован в `app/`.
- [x] Миграции базы данных лежат в `alembic/`.
- [x] Автоматические тесты лежат в `tests/`.
- [x] Архив для сдачи лежит в `dist/`.

## Серверная часть

- [x] Реализована авторизация для администратора и студента.
- [x] Реализованы создание групп, страница группы, удаление группы и очистка связанных данных.
- [x] Реализованы коиновые счета, начисления, списания, переводы, комиссия и лимиты переводов.
- [x] Реализованы создание зачетов, оплата, смена статуса и назначение на группу или студента.
- [x] Реализованы покупка наград и подтверждение заявок администратором.
- [x] Реализованы демо-данные с защитой от повторного восстановления удаленных демо-групп.
- [x] Реализована смена пароля администратора из настроек.

## Интерфейс

- [x] Реализованы лендинг, вход и регистрация с локальными ассетами.
- [x] Реализован CRM-интерфейс администратора: панель управления, группы, студенты, зачеты, транзакции, награды и настройки.
- [x] Реализован студенческий кошелек: баланс, переводы, история, зачеты и вкладка настроек.
- [x] Реализованы модальные подтверждения и searchable combobox.
- [x] Убрана зависимость от внешних CDN для ресурсов интерфейса во время работы приложения.

## Тестирование

- [x] Покрыты авторизация и доступы по ролям.
- [x] Покрыты коиновые операции и крайние случаи.
- [x] Покрыты назначение и оплата зачетов.
- [x] Покрыты покупка и подтверждение наград.
- [x] Покрыты удаление групп и поведение демо-инициализации.
- [x] Покрыты настройки администратора и контракты launch-скриптов.
- [x] Добавлены тесты сдачного сценария для документации и материалов запуска.

## Упаковка

- [x] `start.bat` отвечает за первый запуск.
- [x] `app.bat` отвечает за обычный запуск после настройки.
- [x] `reset_data.bat` удаляет локальные файлы базы данных только после подтверждения.
- [x] README описывает запуск, тесты, репозиторий и сдачные материалы.
