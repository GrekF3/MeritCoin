# Отчет о тестировании

## Область проверки

Тестирование покрывало Neuro Coin как локальное FastAPI-приложение для учебной CRM-системы с ролями администратора и студента.

Проверялись:

- авторизация и регистрация;
- панель управления администратора, группы, студенты, зачеты, награды, транзакции и настройки;
- студенческий кошелек, переводы, история, зачеты и награды;
- коиновый ledger, комиссия, лимиты переводов, идемпотентность и защита баланса;
- удаление групп и стабильность демо-инициализации;
- Windows-скрипты запуска и сброса данных;
- наличие сдачной документации.

## Окружение

- Дата: 2026-06-18
- ОС для автоматической проверки: локальное macOS-окружение разработки
- Runtime: Python 3.14 в текущем локальном shell для автоматических тестов
- Целевая среда выполнения сдачной версии: Python 3.12+ на Windows через `.bat`-скрипты
- База данных: SQLite в тестах и локальном запуске приложения

## Ручные сценарии

Ручные сценарии подготовлены участниками проекта по кейсам из `docs/test-cases.md`.

Основные роли:

- администратор/преподаватель;
- студент/участник;
- локальный оператор, запускающий Windows-скрипты.

Фокус ручной проверки:

- первый запуск и демо-данные;
- вход по ролям;
- регистрация студента;
- начисление, списание и перевод коинов;
- оплата зачета;
- покупка и подтверждение награды;
- настройки администратора и смена пароля;
- удаление группы;
- сброс локальных данных.

## Итог

Проект прошел автоматический набор тестов и готов к сдаче после обновления архива в `dist/` из финального состояния репозитория.
