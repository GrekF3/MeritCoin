# Тест-кейсы

## TC-01: Первый запуск с демо-данными

- Роль: локальный оператор
- Шаги: запустить `start.bat`, выбрать создание демо-данных, дождаться открытия браузера.
- Ожидаемый результат: база данных мигрирована, демо-пользователи созданы, приложение открывается на `http://127.0.0.1:8017`.

## TC-02: Вход администратора

- Роль: администратор
- Шаги: открыть `/login`, ввести `admin / admin` для демо-данных.
- Ожидаемый результат: пользователь перенаправлен на `/admin`, панель управления отображается.

## TC-03: Вход студента

- Роль: студент
- Шаги: открыть `/login`, ввести `student / student` для демо-данных.
- Ожидаемый результат: пользователь перенаправлен на `/me`, видны баланс кошелька и студенческая навигация.

## TC-04: Регистрация студента

- Роль: студент
- Шаги: открыть `/register`, ввести логин, имя, пароль и группу.
- Ожидаемый результат: созданы пользователь, членство в группе и коиновый счет; пользователь может войти.

## TC-05: Начисление коинов администратором

- Роль: администратор
- Шаги: открыть профиль студента, ввести сумму и причину, отправить форму начисления.
- Ожидаемый результат: баланс студента увеличивается; транзакция появляется в истории администратора и студента.

## TC-06: Списание коинов администратором

- Роль: администратор
- Шаги: открыть профиль студента с балансом, ввести сумму и причину, отправить форму списания.
- Ожидаемый результат: баланс студента уменьшается; попытка списать больше баланса отклоняется.

## TC-07: Перевод коинов студентом

- Роль: студент
- Шаги: войти под студентом с балансом, выбрать другого студента из той же группы, ввести сумму и причину, отправить перевод.
- Ожидаемый результат: баланс отправителя уменьшается на всю сумму; получатель получает сумму за вычетом комиссии; системный счет получает комиссию.

## TC-08: Проверка лимита перевода

- Роль: студент
- Шаги: попытаться перевести больше разрешенного процента от баланса.
- Ожидаемый результат: перевод отклоняется с понятной ошибкой валидации.

## TC-09: Оплата группового зачета

- Роль: студент
- Шаги: открыть студенческий кошелек, выбрать активный групповой зачет, оплатить коинами.
- Ожидаемый результат: баланс уменьшается на стоимость зачета; зачет получает статус оплаченного; повторная оплата блокируется.

## TC-10: Видимость индивидуального зачета

- Роль: студент
- Шаги: создать индивидуальный зачет для одного студента, войти под другим студентом.
- Ожидаемый результат: другой студент не видит и не может оплатить индивидуальный зачет.

## TC-11: Покупка награды

- Роль: студент
- Шаги: войти с достаточным балансом и купить доступную награду.
- Ожидаемый результат: баланс уменьшается; заявка появляется у администратора в статусе ожидания.

## TC-12: Подтверждение награды

- Роль: администратор
- Шаги: открыть страницу заявок и подтвердить ожидающую заявку.
- Ожидаемый результат: заявка получает статус выполненной; повторное подтверждение отклоняется.

## TC-13: Настройки переводов

- Роль: администратор
- Шаги: открыть настройки, изменить процент комиссии и максимальный процент перевода.
- Ожидаемый результат: новые значения сохраняются и применяются к следующим переводам.

## TC-14: Смена пароля администратора

- Роль: администратор
- Шаги: открыть настройки, ввести текущий пароль, новый пароль и подтверждение.
- Ожидаемый результат: хеш пароля изменяется; старый пароль больше не работает; новый пароль работает.

## TC-15: Удаление группы

- Роль: администратор
- Шаги: удалить группу со студентами, счетами, транзакциями, зачетами и оплатами.
- Ожидаемый результат: группа и связанные записи удалены; архивированные пользователи не блокируют повторное использование логина.

## TC-16: Сброс локальных данных

- Роль: локальный оператор
- Шаги: запустить `reset_data.bat`, ввести любой текст кроме `DELETE`, затем запустить снова и ввести `DELETE`.
- Ожидаемый результат: первый запуск отменяется; второй запуск удаляет локальные SQLite-файлы базы данных.
